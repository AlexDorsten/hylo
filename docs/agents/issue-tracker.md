# Issue tracker

Use GitHub Issues and pull requests in `AlexDorsten/hylo`, with `gh --repo
AlexDorsten/hylo` explicitly specified. The upstream repository is a reference,
not a publishing target. PRs target `dev` and branches use `codex/`.

Read an issue before changing its status. Use `--body-file` for multiline issue,
comment and PR text. Close an issue only when its acceptance criteria are met;
link partial work without a closing keyword. Public text, test data and review
images must follow the fork privacy boundary in `CLAUDE.md`.

Assess optional AI assistance for each community feature and record the result in
its issue and `docs/community/ai-assistance.md`.
